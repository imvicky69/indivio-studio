# Indivio Studio

> **Digital Product & Software Engineering Studio**  
> High-performance Web Applications, Native Mobile Apps (iOS & Android), Coaching & School ERPs, and Custom Enterprise Platforms.

## About Indivio Studio

Indivio Studio is an elite software engineering and digital product studio founded in Nirmali, Bihar, serving businesses, institutions, and startups across India.

- **Founder & Lead Engineer**: Vikky Raja
- **Core Stacks**: Next.js (App Router), React, TypeScript, Tailwind CSS, Node.js, Firebase, Cloud Architecture, Three.js / Antigravity.
- **Flagship Solutions**:
  - Native On-Demand Mobile Apps (e.g. Lele Delivery App on Google Play Store)
  - Progressive Web Stores & E-Commerce Platforms
  - Indivio Studio Campus Suite (School & Coaching Institute ERP)
  - Bespoke SaaS & High-Converting Web Platforms

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
